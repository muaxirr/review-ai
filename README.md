# ReviewAI — Старт проекта

1. Распакуй этот архив в любую папку на компьютере.
2. Открой терминал внутри папки `review-ai` и выполни:
   ```bash
   npm install
   npm run dev
   ```
3. Открой в браузере `http://localhost:3000`.

Этот же проект работает как веб-сайт и устанавливается на телефон (iPhone / Android) через меню браузера «Добавить на экран Домой».
